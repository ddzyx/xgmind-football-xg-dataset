# XG Mind — Open Historical Football Match & xG Dataset

> *Compiled from publicly available sports statistics and processed by XG Mind Data Engine ([https://xgmind.com](https://xgmind.com/)).*

Open, normalized historical football match results and expected goals (xG) dataset covering completed fixtures across major European leagues (Premier League, La Liga, Serie A, Bundesliga, Ligue 1, and continental competitions).

## Dataset Format

- `data/european_football_xg_matches.csv` — UTF-8 normalized CSV for quick inspection and SQL/R/Python ingestion.
- `data/european_football_xg_matches.parquet` — Columnar Parquet file for high-speed analytical pipelines (DuckDB / Polars / Pandas).
